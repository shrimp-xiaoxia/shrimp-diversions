# 虾趣社区

> 一个仿小红书的图文社区平台，基于 Spring Cloud Alibaba 的微服务实践项目。

## 项目简介

虾趣社区是一个面向图文社区的完整后端系统，覆盖笔记发布、点赞、收藏、评论、关注、搜索与对象存储等核心链路，配套一个基于 Vue 3 的前端。项目按业务域拆分为多个独立服务，通过网关统一暴露接口，用 Nacos 做服务发现与配置中心，用 RocketMQ 解耦跨服务的异步流程。

社区类业务的难点集中在两处：一是点赞、收藏、评论计数这类高频写操作对数据库造成的压力；二是发布笔记、关注、评论等跨服务操作需要保证最终一致。项目针对这两点做了如下设计：热点数据走 Redis 缓存并用 Lua 脚本保证原子性，计数与通知通过 RocketMQ 异步消费落库，搜索索引由 Canal 订阅数据库变更后写入 Elasticsearch，大文本内容存入 Cassandra，分布式 ID 由 Leaf 生成，从而在保证响应速度的同时避免单点瓶颈。

## 功能特性

- **用户**：验证码登录、资料查看与修改、个人主页
- **笔记**：发布、详情、发现流、关注流、频道与话题
- **互动**：点赞、收藏、一级与二级评论、关注与粉丝关系
- **搜索**：笔记与用户检索，基于 Elasticsearch
- **基础设施**：文件上传（MinIO / 阿里云 OSS）、分布式 ID、统一鉴权、操作日志
